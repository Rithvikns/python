"""
Structural Design Patterns in Python

This file contains information about structural design patterns.

## Structural Design Patterns
Structural design patterns help define clear relationships between objects and classes, making large systems easier to manage and scale.

### 1. Factory Method
- Provides an interface for creating objects in a superclass but allows subclasses to alter the type of objects that will be created.
- Helps in promoting loose coupling by decoupling object creation from its implementation.

### 2. Adapter
- Allows incompatible interfaces to work together by wrapping one class inside another.
- Useful when integrating third-party libraries or legacy code.

### 3. Bridge
- Separates abstraction from its implementation, allowing them to evolve independently.
- Useful when dealing with complex class hierarchies.

### 4. Composite
- Composes objects into tree structures to represent part-whole hierarchies.
- Allows clients to treat individual objects and compositions of objects uniformly.

### 5. Decorator
- Dynamically adds behaviors to objects without modifying their structure.
- Useful when extending functionality without altering existing code.

### 6. Facade
- Provides a simplified interface to a larger body of code.
- Hides complexities by exposing only high-level operations.

### 7. Flyweight
- Minimizes memory usage by sharing as much data as possible with similar objects.
- Useful in systems with a large number of similar objects.

### 8. Proxy
- Acts as a placeholder for another object, controlling access to it.
- Useful for implementing lazy loading, access control, logging, etc.

These patterns help improve code maintainability, flexibility, and reusability in large-scale software design.
"""
